# Geführte Fehlersuche

Für alle, die das Modul nutzen oder weiterentwickeln: Diese Seite verweist auf die Doku im Modul.

- [Bedienanleitung](https://github.com/johanneshar/iot-platform/blob/main/modules/troubleshooting/docs/anleitung.md)
- [Schulung](https://github.com/johanneshar/iot-platform/blob/main/modules/troubleshooting/docs/schulung.md)
- [Entwicklerdoku](https://github.com/johanneshar/iot-platform/blob/main/modules/troubleshooting/docs/entwickler.md)

Kurz: Fehlerbäume zu Alarmen ([ADR-007](/adr/ADR-007-fehlerbaum-format)), Schritt für Schritt bis zur Lösung;
Einstieg per Deep Link aus Alarmliste und Dashboard. Lösungswege werden mit Benutzer und Zeit dokumentiert
(E-35). Mindeststufe `standard`, nicht GxP-relevant.
